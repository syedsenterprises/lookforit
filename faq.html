About the Site

What is LookForIt?

LookForIt is a curated directory and resource hub for AI tools, useful websites, and online resources. Our goal is to save you hours of research by organising the best tools and guides in one consistently structured directory.

Who runs LookForIt?

LookForIt is independently run by Shahid. The site is not affiliated with any AI company or tool provider listed in the directory. Our goal is to provide honest, unbiased descriptions of each tool based on publicly available information.

How often is the directory updated?

We aim to update tool entries when significant changes occur — such as new pricing, major feature launches, or product shutdowns. New tools are added on a rolling basis. The site is not updated on a fixed schedule but is reviewed regularly.

Does LookForIt endorse the tools listed?

Listing a tool does not constitute an official endorsement. We aim to describe tools accurately based on available information, but we encourage you to do your own research and trial before committing to any paid tool. Read our Disclaimer for more details.

Using the Directory

How do I submit my tool?

Use the submission form on the Submit Tool page. Standard listings start at $49 and featured placement at $129. All listings are reviewed manually before publication, and payment instructions are sent by email after acceptance.

Why is the directory empty right now?

LookForIt was rebuilt from zero in October 2026. Rather than carry over unverified entries, we started clean. Listings appear only after manual editorial review.

Free Tools

What are the free tools?

Twenty built-in utilities on the Free Tools page: an AI cost calculator, prompt builder, word counter, JSON formatter, password generator, color palette and gradient generator, meta tag generator, text toolkit, unit converter, Markdown preview, focus timer, Base64 encoder and decoder, UUID generator, regex tester, color contrast checker, Lorem Ipsum generator, CSV to JSON converter, text diff, stopwatch and countdown, and random picker. They work immediately, with no account.

Do the free tools send my data anywhere?

No. Every free tool runs entirely in your browser. Nothing you type is sent to a server, stored, or tracked. Closing the tab removes it.

Are the AI cost calculator prices verified?

No. Provider prices change often, so the calculator's rates are editable example values. Always check your provider's current pricing before budgeting — results are estimates only.

Do the free tools work offline?

Once the page has loaded, yes — the tools need no network connection, API key, or live data. The unit converter deliberately excludes currency, because exchange rates would need a live feed.

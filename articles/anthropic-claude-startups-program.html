Claude for Startups Program: Benefits and Status

Anthropic’s Claude for Startups program for early-stage founders: what members get, the current cohort status, and where to watch for the next one.

What Claude for Startups is

Claude for Startups is Anthropic’s program for early-stage founders building on Claude. Members get access to offers, tools, and events to help run their business using Claude, including the Claude products startups build with: Claude models through a single integration, Claude Code for building and debugging across a codebase, and production agents built with MCP, code execution, and tool use.

Related listings in our directory: Claude and Anthropic API.

Current status: the cohort is full

Read this first: Anthropic’s official program page states that the current cohort is now full and it is not accepting new applications right now. Interest was far higher than expected, and applications still in review could not be moved forward. If you want in, the official route is the Claude Startup newsletter, which announces when applications open for the next cohort.

Program membership continues for current members. That matters because it means the benefits below describe the live program for members, not a promise to new applicants today. Terms for the next cohort are not published on the page yet — check the official page before planning around any specific benefit.

What members get

The Claude Startup Stack. Members get access to discounts and credits worth up to $45,000 from companies building with Claude, across sales, design, data, meetings, and engineering. Each offer is redeemed with a code inside the Claude Console.

Applied AI sessions. Live group sessions with Anthropic’s Applied AI team, held every other week in webinar format, each covering a topic and including an AMA. Members get a registration link by email and in the Claude Startups portal.

Events and community. Founder House, Founder Days, Builder Days, and hackathons hosted by Anthropic, plus founder-organized meetups, demo nights, livestreams, and AMAs.

Extra credits through a VC. Startups backed by a VC in Anthropic’s partner network may be eligible for up to $100,000 in additional API credits, claimed through that VC.

One important limit

Claude Startups credits apply to the first-party Claude API through Claude Console. They cannot be used on AWS, Google Cloud, Azure, or other third-party platforms. If your stack runs Claude through Bedrock or Vertex, these credits do not transfer — plan your architecture with that in mind.

Frequently asked questions

What is the Claude for Startups program?

Claude for Startups is Anthropic’s program for early-stage founders building on Claude. Members get access to offers, tools, and events to help run their business using Claude.

Can I apply to Claude for Startups right now?

No. Anthropic’s official program page states that the current cohort is now full and it is not accepting new applications right now. Subscribe to the Claude Startup newsletter to hear when applications open for the next cohort.

What is the Claude Startup Stack?

Offers from AI-native companies building on Claude, across sales, design, data, meetings, and engineering, worth up to $45,000 in total. Members redeem each offer with a code in the Claude Console.

How do Applied AI sessions work?

Applied AI sessions are live group sessions for members, held every other week in a webinar format. Each one covers a topic and includes an AMA with Anthropic’s Applied AI team. Members get a link to register by email and in the Claude Startups portal.

Can I use Claude Startups credits on AWS, Google Cloud, or Azure?

No. Claude Startups credits apply to the first-party Claude API through Claude Console. They can’t be used on AWS, Google Cloud, Azure, or other third-party platforms.

I’m backed by a VC in Anthropic’s partner network. Can I get API credits?

You may be eligible to receive up to $100,000 in additional API credits, claimed through your VC.
